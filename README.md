# Titanic Survival Prediction

A machine learning project that predicts whether a passenger survived the Titanic disaster.

## What I did
- Loaded the Titanic dataset using seaborn
- Cleaned the data: filled missing age values and converted sex into numbers
- Split the data into 80% training and 20% testing
- Trained two models: Logistic Regression and Decision Tree

## Results
- Logistic Regression accuracy: 80.4%
- Decision Tree accuracy: 79.9%
- Both models performed almost the same. Logistic Regression was slightly better.

## Tools used
Python, pandas, seaborn, scikit-learn, Google Colab

## Features used
Passenger class, sex, age, and fare
